# VLM・VLA の数理：演習コード

資料「[VLM・VLA の数理を学ぶロードマップ](https://mamoru1126.github.io/humanoid_study/vla-math/)」の各章で使う演習コードです。機械学習の基礎から、VLM、VLA、蒸留までの考え方を、小さな問題で実際に動かして確かめます。

## 必要なもの

- Python 3
- numpy
- matplotlib

GPU は要りません。どの演習も、CPU で 1 秒〜20 秒ほどで終わります。numpy と matplotlib が入っていないときは、リポジトリの一番上で次のコマンドを実行します。

```bash
pip install -r vla_math/requirements.txt
```

図には日本語のラベルがあります。日本語のフォントが見つからないときは、実行時に注意が出ます。Ubuntu では、次のコマンドでフォントを入れられます。

```bash
sudo apt install fonts-noto-cjk
```

## 動かし方

リポジトリの一番上で、章の番号のファイルを実行します。たとえば 1 章の演習は次のとおりです。

```bash
python3 vla_math/ch01_regression.py
```

図は `docs/vla-math/figures/` に保存されます。資料のページに載せている図と同じファイルなので、実行すると上書きされます。

`common.py` は、図の保存先、色、日本語フォントの設定をまとめたものです。

## 結果の例

資料に載せている数値は、次の「確認の状況」の環境で実行したときの出力です。乱数の種を固定してあるので、同じ環境なら同じ数値になります。numpy のバージョンが違うと、少し変わることがあります。

| 章 | 主な結果 |
| --- | --- |
| 1 | 9 次の多項式は、学習データの誤差 0.008、検証データの誤差 4.030（過学習）。3 次は 0.085 と 0.318 |
| 2 | softmax 回帰の検証データの正解率 93.1%。逆伝播の勾配と数値微分の相対誤差 3.3e-10 |
| 3 | 線形のモデル 63.7%、隠れ層 2 つのネット 99.9%。逆伝播と数値微分の相対誤差は最大 2.6e-07 |
| 4 | BPE で 1 文 14.8 トークンが 3.7 トークンに。バイグラムの損失は、1 文あたり 文字 9.68、BPE 6.83 |
| 5 | 因果マスクがあると、先のトークンを変えても前の出力は変わらない（差 0）。KV キャッシュは全部を計算し直した結果と一致 |
| 6 | 224×224 画素を 16 画素ずつに切ると 196 トークン。位置の埋め込みがないと、パッチの並べ替えを区別できない |
| 7 | ゼロショット分類 99%。学習で見ていない「緑のボール」も、CLIP の損失で 97%、SigLIP の損失で 100% |
| 9 | 行動クローニングの失敗は T = 100 で 11.9%、T = 800 で 68.5%。DAgger はどの長さでもほぼ 0% |
| 10、13 | フロー 1 ステップは平均に落ちる（山に入った割合 0%）。10 ステップで 96.5%。蒸留した生徒は計算 1 回で 96.2% |
