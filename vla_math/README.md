# VLM・VLA の数理：演習コード

資料「[VLM・VLA の数理を学ぶロードマップ](https://mamoru1126.github.io/humanoid_study/vla-math/)」で使う演習コードです。学習、推論、蒸留が数式の上で何をしているのかを、小さな問題で実際に動かして確かめます。

## 必要なもの

- Python 3
- numpy
- matplotlib

GPU は要りません。numpy と matplotlib が入っていないときは、次のコマンドで入れます。

```bash
pip install -r vla_math/requirements.txt
```

図には日本語のラベルがあります。日本語のフォントが見つからないときは、実行時に注意が出ます。Ubuntu では、次のコマンドでフォントを入れられます。

```bash
sudo apt install fonts-noto-cjk
```

## 演習 1　学習・推論・蒸留を、1 次元の問題で確かめる

リポジトリの一番上で、次のコマンドを実行します。

```bash
python3 vla_math/ex01_learn_infer_distill.py
```

手元の環境では、CPU だけで 24 秒かかりました。

### 場面

ロボットの正面に障害物があります。お手本は、左へ避けるもの（行動 a = −1）と、右へ避けるもの（a = +1）が半々です。正面へ進む行動（a = 0）は、お手本に 1 つもありません。

### やること

| 番号 | 内容 | 見るところ |
| --- | --- | --- |
| (1) 回帰 | 二乗誤差で「1 つの答え」を学習する | 答えが、2 つの山の平均（a = 0）になる |
| (2) 学習 | フローマッチングで速度場を学習する | 学習した速度場が、理論の式に近い。損失は 0 にならない |
| (3) 推論 | ノイズから始めて、オイラー法で N ステップ積分する | N = 1 では平均に落ちる。N を増やすと、2 つの山に分かれる |
| (4) 蒸留 | 10 ステップの教師を、1 回の計算で出す生徒に写す | 生徒は計算 1 回で、教師の 10 ステップとほぼ同じ行動を出す |
| (5) おまけ | 知識蒸留の「温度」を、手で計算できる例で見る | 温度を上げると、正解でないクラスの確率の差が見える |

ニューラルネットは、逆伝播と Adam まで numpy で書いてあります（`MLP` クラス）。

### 結果

手元で実行したときの数値です。乱数の種を固定してあるので、同じ環境なら同じ数値になります。numpy のバージョンが違うと、少し変わることがあります。

| 方法 | 山に入った割合 | ネットの計算 |
| --- | ---: | ---: |
| お手本 | 99.7% | — |
| 回帰（二乗誤差） | 0.0% | 1 回 |
| フロー 1 ステップ | 0.0% | 1 回 |
| フロー 2 ステップ | 39.7% | 2 回 |
| フロー 4 ステップ | 86.7% | 4 回 |
| フロー 10 ステップ（教師） | 96.5% | 10 回 |
| フロー 100 ステップ | 98.8% | 100 回 |
| 蒸留した生徒 | 96.2% | 1 回 |

「山に入った割合」は、どちらかの山の中心（−1 か +1）から 0.3 以内に入った行動の割合です。

### 変えてみる

| 変えるところ | 場所 | 見るところ |
| --- | --- | --- |
| お手本の山を 3 つにする | `MODES`（例：`np.array([-1.5, 0.0, 1.5])`） | 10 ステップで 3 つの山に分かれるか。生徒が教師にどこまで近づくか |
| 教師のステップ数を 100 にする | `main` の `teacher` | 生徒が写しやすくなるか、写しにくくなるか |
| 生徒のネットを小さくする | `distill` の `MLP([1, 64, 64, 1], rng)` | どこまで小さくできるか |
| オイラー法を中点法に替える | `integrate` | 同じ計算回数で、山に入る割合がどう変わるか |

山の数は `MODES` を書き換えるだけで変えられます。山はどれも同じ割合で選ばれ、ばらつきも同じです。

山を −1.5、0、1.5 の 3 つにすると、お手本の平均（0）がまん中の山に重なります。このとき、回帰とフロー 1 ステップの「山に入った割合」は 100% 近くになりますが、行動は平均に落ちていて、左右の山には 1 つも行きません。この場合は、割合の数字ではなく、行動の分布の図（`ex01_samples.png`）で見ます。
